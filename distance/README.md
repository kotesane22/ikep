# レジ待ち距離感診断

公開URL: https://kotesane22.github.io/ikep/distance/

## 構成
- `index.html` … 画面（イントロ → スライダー2問 → 質問8問 → 結果）
- `js/data.js` … 文言・配点・5タイプ・「なぜ近くまで来るの？」（**ここだけで内容調整可**）
- `js/app.js` … 画面遷移・判定・SVG描画・共有リンク
- `css/tokens.css` … 色・フォント・余白（デザイン差し替えはここ）
- `assets/ogp.html` … OGP画像の元データ（1200×630でスクショして `ogp.png` にする）

## 判定ロジック
総合距離指数 = 前に立つ距離×0.55 ＋ 後ろに許す距離×0.45 ＋ 質問の補正合計×0.6
→ A〜50 / B〜75 / C〜105 / D〜140 / E それ以上（`data.js` の `max`）

## 相手と比べる
結果画面の「リンクを送る」で `?n=呼び名&s=前の距離&r=許容距離&t=タイプ` 付きのURLを共有。
相手が診断を終えると、2人の距離感の比較カードが表示される。サーバー送信はなし。
