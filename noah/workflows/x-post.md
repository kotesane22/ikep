# WORKFLOW — X投稿・引用RTを作る

> **使う場面**：Xに投稿する／刺さったポストを引用RTする
> **所要**：10〜20分 ／ **承認**：🔒 **投稿は必須**

## 使うスキル

- `/quote-rt-workflow` … 引用RT（ikeP通信のブランドボイスで生成・AI臭チェック込み）

---

## 単独投稿の型

```
① 1行目で立ち止まらせる（問い or 違和感 or 断言）
② 具体（体験・数字・実例）
③ 読者が今日できること
```

**140字なら、③を削らない。** ①と②を削る。行動が残らない投稿は流れて消える。

## 引用RTの型

`/quote-rt-workflow` を使う（4問ヒアリング → ブランドボイスで生成）。
自分で書く場合の骨格：

```
① 元ポストの「どこが」刺さったかを特定する（漠然と褒めない）
② 自分の経験と接続する
③ 一段深める or 別角度を足す
```

**元ポストの要約で終わらない。** 要約は引用RTではなく転載。
