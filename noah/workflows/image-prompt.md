# WORKFLOW — AI画像プロンプトを設計する

> **使う場面**：AI画像を作る／プロンプトを設計する
> **所要**：15〜40分 ／ **承認**：不要（生成・提案まで）。公開・販売は🔒必須

---

## 手順

### 1. 前提を確認する

- [ ] **添付画像があるか**（ある＝キャラ性保持が最優先になる）
- [ ] 用途（サムネ／挿絵／販売用／実績用）
- [ ] 出力先（ChatGPT画像生成 / Midjourney / その他）
- [ ] 縦横比

### 2. 優先順位を守る（`USER_PROFILE.md` §8）

添付画像がある場合、**キャラクター性・顔・髪型・色・雰囲気・画風を最優先で保持**する。

```
1. 顔・表情・瞳
2. キャラ性の保持
3. AIっぽさの除去
4. 構図の強さ
5. 世界観の独自性
6. 書き込み量
7. エフェクト（主役を邪魔しない範囲）
```

### 3. 技法を選ぶ

**使ってよい**：世界圧縮構図 / 瞳奥行き三層 / フィボナッチスパイラル / 魚眼 /
二重露光 / 光粒子 / 虹色収差 / 情報源を活かす表現

> **ただし既存技法に寄せすぎない。**
> 毎回**1つは、いけP独自の技法名・構図名・表現ルールを提案する。** ここが差別化の本体。

### 4. NGを外す（`USER_PROFILE.md` §7）

- [ ] 左右対称すぎる顔になっていない
- [ ] 感情の浅い表情になっていない
- [ ] 意味のない過剰装飾がない
- [ ] 説明的すぎる小物がない
- [ ] ソシャゲ風テンプレになっていない
- [ ] プラスチックのような肌になっていない
- [ ] 画面全体が均一に描き込まれていない（**主役を立てる**）
- [ ] 文字の破綻・手指の破綻・顔まわりのノイズがない

### 5. 3形態で出す

| 版 | 用途 |
|---|---|
| **実用版** | 普段使い。コピペしてすぐ回せる長さ |
| **短縮版** | 文字数制限がある時 |
| **完全版** | 世界観を作り込む時。全パラメータ入り |

**必ずコピペ可能な形（コードブロック）で出す。**

### 6. 数を出す場合

画像案・企画案・闇鍋プロンプトは、**必要に応じて20案**出す。
20案の時は、**似た案を並べない**。方向性を散らす。
